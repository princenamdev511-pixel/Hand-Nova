# Hand Nova ✋

Hand Nova is a web-based hand gesture detection project that uses a camera to capture hand movements and provides an interactive experience using hand tracking technology.

## Features

* Real-time hand detection using a camera
* Hand gesture tracking
* Interactive hand capture functionality
* Camera on/off controls
* Simple and clean user interface
* Responsive web interface

## Technologies Used

* HTML
* CSS
* JavaScript
* React.js
* Hand Tracking Technology

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd hand-nova
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Requirements

* Node.js and npm
* A modern web browser
* Camera access
* Internet connection if external libraries or resources are required

## How to Use

1. Open Hand Nova in your browser.
2. Allow camera permission when prompted.
3. Start the hand capture feature.
4. Show your hand in front of the camera.
5. Use the available controls to interact with the application.

## Project Purpose

The purpose of Hand Nova is to explore camera-based hand detection and gesture tracking through an interactive web application.
